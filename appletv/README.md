# ReelHouse for Apple TV

Native SwiftUI client (tvOS 17+) for a ReelHouse media server: Movies & TV, Music and Podcasts,
with one shared audio player. A standalone Xcode project with no package dependencies.

- Project: `ReelHouseTV.xcodeproj`, scheme and target `ReelHouseTV`, display name `ReelHouse`
- Bundle id `com.reelhouse.client.tv`, team `G4GK5372G8`
- Sources are a file-system-synchronized group: any file added under `ReelHouseTV/` is compiled

## Build and run

Open `ReelHouseTV.xcodeproj`, pick the `ReelHouseTV` scheme and an Apple TV (or simulator), Run.
The setup screen lists ReelHouse servers found over Bonjour (`_reelhouse._tcp`); or type the
address, e.g. `http://192.168.1.50:3350`.

```bash
# compile check
xcodebuild -project ReelHouseTV.xcodeproj -scheme ReelHouseTV -configuration Debug \
  -destination 'generic/platform=tvOS Simulator' CODE_SIGNING_ALLOWED=NO build

scripts/release.sh                      # archive + upload to TestFlight (needs the App Store Connect record)
python3 scripts/make-placeholder-icon.py   # regenerate the placeholder icon / Top Shelf art (needs Pillow)
```

Debug builds accept launch arguments for testing without a remote: `-debugSection movies|music|podcasts|settings`,
`-debugSettingsPage mediaLibraries|folderPicker|music|podcasts|speaker|audioFolderPicker`,
`-debugFocusWalk 8`, `-debugBriefing YES`.

## What is in it

- `Movies/` - library with hero, Continue Watching and shelves, search, detail pages with seasons
  and episodes, the system player with resume, subtitles, progress reporting and next episode,
  My List, "+ Add" downloads and the Downloads queue with the VPN light, imported lists, and the
  admin's library management (folders, network computers)
- `Music/`, `Podcasts/` - both tabs, including music "+ Add" and Suggested for You
- `Audio/` - the shared player, Now Playing, speakers ("let others play here"), wake-up alarms,
  the Morning Briefing, listening stats and the audio settings
- `App/`, `Networking/`, `Views/`, `Design/`, `Models/` - connection and Bonjour discovery,
  cookie sign-in, the HTTP client, server setup / login / Settings, theme and the server-version banner

Tabs: Movies, Music, Podcasts, Settings. Each media tab appears only while the server reports that
section switched on (`/api/media/enabled`, `/api/audio/enabled`).

Server defaults: HTTP 3350, HTTPS 3453. The server's certificate comes from its own authority,
which a TV doesn't trust; the app then falls back from `https://` to `http://host:3350`, but only
after checking the HTTPS certificate against the authority it remembered for that server
(`Networking/ServerIdentity.swift`, `/api/certificate-authority`).

The session cookie is mirrored into UserDefaults (`SessionCookieStore` in
`Networking/ReelHouseClient.swift`) because tvOS may reclaim URLSession's cookie jar at any time.

Release builds define `STORE_BUILD`, which hides everything torrent-related ("+ Add", Downloads,
Import a List, suggestions) - App Review rejects those. Debug builds keep them. Remove the flag
from the project's Release settings to ship them in a Release build.

## Server API used

`/api/health`, `/api/auth/*`, `/api/certificate-authority`, `/api/media/**` (including
`/api/media/downloads/**`), `/api/music/**` (including `/api/music/downloads/**`),
`/api/podcasts/**`, `/api/audio/**`, and for the admin's Music / Podcasts settings pages
`GET /api/settings/schema`, `GET /api/settings` and a `PUT` to the `endpoint` each schema section names.

## Dropped from the app this was extracted from

Live cameras and the live-stream players, the alert/event feed and full-screen alert takeover,
the home security alarm, Device Hub, Weather (and its warning banner), the Organizer (and the
OrganizerKit package), Family Files, push notifications (with the entitlements file and APNs
registration), the licence check and its watermark, and the camera / account / timeline calls in
the client. The Morning Briefing remains, with the date and podcast episodes only.

## App icon

Placeholder art (a film reel inside a house) generated by `scripts/make-placeholder-icon.py` into
`Assets.xcassets/App Icon & Top Shelf Image.brandassets`: the layered parallax icon (Back holds
the background, Front the glyph, Middle is empty) and both Top Shelf images. Replace when real
ReelHouse art exists.
